# Open Graph preview images

The metadata helper accepts PNG files only when they are exactly 1200×630 pixels. Use
`default-og.png` for the fallback and `<route>-og.png` for page-specific previews, with concise
visual text and a matching metadata description. Compress files before committing them.

The current 1×1 PNG files are placeholders and are intentionally ignored. Replace them with real
1200×630 artwork; missing or invalid images are omitted safely rather than referenced.
