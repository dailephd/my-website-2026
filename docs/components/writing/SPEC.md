# Writing Components Specification

> Historical M10 specification for retained/tested writing components. No `/writing` route is
> active; see `docs/CONTRACT.md` and `docs/COMPONENT_MAP.md` for current route and reachability.

`WritingCard` renders verified published metadata, textual type/status labels, optional dates,
tags, source information, and a safe link. `WritingEmptyState` explains the verified-empty state
and receives useful pathways through props. Neither component implements article processing.
