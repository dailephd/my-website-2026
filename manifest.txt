==========================================================================

Project: dailephd LLC's business, technical projects, AI work and scientific
background website. Next.js 15 App Router, React 19, TypeScript, Tailwind 3,
Vitest, Playwright; Resend is used ONLY for the contact email flow.

There is ONE website application. No monorepo, apps/, packages/, separate CMS,
Postgres, ORM, Python analysis service, extra API service, cloned content
package, or parallel frontend design-system architecture.

  src/types -> src/content -> src/lib/content -> src/app -> feature components
  src/lib/seo -> src/app/metadata + src/components/seo

Do not import React into src/content; do not put project-specific records in
src/components/ui; do not hardcode content arrays in src/app routes; do not
import feature/page-level components into lower content/type layers.

legacy page trees to make obsolete tests pass. Never infer a route from an
